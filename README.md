# Arc'teryx Product Architecture

Independent research study by Felipe Mattos.

This project combines:
- Arc'teryx product architecture and naming conventions
- Amer Sports strategy and growth signals
- hypotheses about customer decision-making
- repair / circularity direction
- hypotheses for internal product, digital and customer analytics

The goal is to show how fragmented public signals can be turned into testable business questions.

The site uses an editorial layout with local photography assets, responsive styles, accessible navigation and expandable research details. Verified sources, design rationale and study limitations are documented in [RESEARCH.md](RESEARCH.md).

## Local preview
Open `index.html` in a browser or serve the repository with any static HTTP server. No build step or runtime dependencies are required.
